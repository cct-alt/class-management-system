# 課堂管理與抽籤系統 2026

這是一個專為中學老師設計的課堂動態管理工具。

## 🌟 功能特點
1. **班級快速切換**：支援 1A, 3B, 3C, 3D, 4X3生物。
2. **無紙化書本檢查**：快速勾選，自動扣分。
3. **動態課堂抽籤**：具有跳動動畫的隨機抽籤系統，抽中可一鍵評分。
4. **快速加扣分**：大按鈕觸控，數據即時同步至 Google Sheets。

## 🛠️ 開發與部署
* 前端發布：利用 GitHub Pages 免費靜態託管。
* 後端資料庫：Google Sheets + Google Apps Script Web App。
